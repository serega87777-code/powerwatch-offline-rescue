Community repair notes

MATRIX PowerWatch X Offline Rescue

Privacy-safe public guide for restoring basic local operation of legacy PowerWatch devices after the original cloud services stopped working.

Status

A BLE rescue flow was confirmed on one PowerWatch X device: the watch accepted local time sync, saved settings, exited the pairing/sync screen, and displayed the normal time screen.

Not official. These are community repair/interoperability notes, not a vendor release.

What is intentionally removed

  • owner name
  • local Windows username and paths
  • phone model
  • private watch MAC address
  • private serial number

What to build publicly

Prefer a clean-room BLE utility that scans/selects a watch, writes current time/timezone, saves settings, and exits safely. Avoid redistributing patched proprietary APKs or vendor assets.

Core BLE commands

CommandMeaning
840107{UTC}{TZ}Set UTC time and timezone offset in minutes
84010811223344Example pair code from legacy notes
8421Save data to memory
8440Show sync animation / visible effect probe
8441Hide sync animation
810F050082SOFF / normal exit observed in app flow

Timezone encoding

840107{8 hex digits Unix UTC}{4 hex digits timezone minutes}

UTC+1 = 003C
UTC+2 = 0078
UTC+0 = 0000

Dangerous commands

Do not send automatically:

8422 = Factory Reset / Unpair
8425 = Enter Shipmode
8430522C5E08 = Debugger Lock

Success criteria

Do not rely only on app-side “pairing success”. Verify the physical watch leaves pairing/sync screens, displays the normal face, shows the expected time, and keeps time after disconnect.
