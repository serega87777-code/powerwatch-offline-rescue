# Notice

This repository is an independent community repair/interoperability project for legacy PowerWatch hardware.

It is not affiliated with, endorsed by, sponsored by, or supported by MATRIX Industries, PowerWatch, or any original vendor entity.

Trademarks and product names are used only to describe compatibility with user-owned devices.

This repository intentionally does **not** include:

- the original vendor APK;
- modified/repacked vendor APKs;
- copied vendor artwork, icons, UI assets, or branding;
- decompiled vendor source or smali;
- private protocol PDFs;
- private watch MAC addresses or serial numbers.

The clean-room Android prototype is original code implementing observed BLE interoperability behavior for repair/preservation purposes.
